# LIVE
Owns: `/go`, `lib/live/`, the Live token route.
1. Giant arrow view first: full-screen arrow, contrast modes black/yellow, black/white, white/black, vibration, speech, VoiceOver labels. Works from fixtures with tap to advance.
2. Camera view: camera feed with a perspective floor arrow that turns with the compass, step card on top.
3. Gemini Live agent: short-lived token from the server, route + keyframes as context, 1 fps camera frames, tools `go_to_waypoint`, `warn`, `arrived`.
